为知笔记官方账号笔记内容迁移到私有部署账号

2026-06-29

为知笔记支持自建 docker
但是原来的为知笔记账号和自己搭建的 docker 服务账号是不互通的，数据也没法同步过来。

下面说下如何迁移数据的方法:

  1. 为知笔记 exe 需要是官网下载的版本，这样数据就会保存在 C:\Users\xxxx\Documents\My Knowledge\Data\xxxxxxxx@xxx.com
  2. 使用新账号登录为知笔记，使用自建的docker服务.这时就会在 C:\Users\xxxx\Documents\My Knowledge\Data\ 目录下创建了该账号的对应的目录。
  3. 拷贝旧账号下的笔记目录到新账号目录下。
  4. 从旧目录中的 index.db 数据库的 WIZ_DOCUMENT 表中将 DOCUMENT_OWNER 字段的值修改为新账号的值，将 WIZ_VERSION 值修改为 -1
  5. 上一步可用 SQL 语句：UPDATE WIZ_DOCUMENT SET WIZ_VERSION = -1 以及 UPDATE WIZ_DOCUMENT SET DOCUMENT_OWNER = 'xxxxxxxxx@xxx.com'
  6. 将 WIZ_DOCUMENT 表数据导出，然后导入到新账号目录下的 index.db 的 WIZ_DOCUMENT 表中即可。
  7. 重新打开为知笔记，等待数据上传到自己的 docker 服务即可。

注意：如果不想导出再导入 WIZ_DOCUMENT 表，可以直接清空原 index.db 数据库中的 WIZ_META 表，这个表里存的是官方账号登录凭证，之后打开为知笔记重新登陆 docker 服务账号即可。
