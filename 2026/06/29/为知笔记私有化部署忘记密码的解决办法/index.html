为知笔记私有化部署忘记密码的解决办法

2026-06-29

为知笔记（WizNote）私有化部署（Docker）重置密码需直接操作数据库，因无邮件重置功能时默认无法通过界面找回。‌‌

  1. 登录容器并查初始密码‌：运行 cat /wiz/app/entrypoint.sh 查看 MySQL root 密码（若未修改过），默认管理员账号通常为 admin@wiz.cn / 123456。
  2. 进入 MySQL 数据库‌：使用 mysql -uroot -p密码来自上述脚本 后执行 USE wizasent;。
  3. 查询并更新密码‌：执行 SELECT * FROM wiz_user; 确认目标用户 ID 和 GUID，再用 UPDATE wiz_user SET PASSWORD='计算得出的密码' WHERE ID=1;
    （注意：密码需为 MD5 加密后的字符串‌，如原始密码 123456 应先计算其 MD5(MD5(MD5(MD5(123456))) 拼接 GUID)。
    （注意：系统管理员的 GUID 为 00000000-0000-0000-0000-000000000000，其计算得出的密码为 a9da87c000d58437ffd94b020dc221c9）
  4. 重启服务生效‌：docker restart <容器名>，之后用密码 123456 登录。‌‌

注意事项：

  • 若已配置 SMTP（管理员后台 → SMTP 设置），可尝试网页端点击“忘记密码”通过邮箱重置；否则‌必须数据库直改‌。
  • 操作前备份 /wiz/storage 目录，避免数据丢失。
  • MD5 可用命令如 echo -n "新密码" | md5sum 生成（Linux/macOS），或使用 在线 MD5 生成器。‌‌
